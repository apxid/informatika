📋 Checklist Solusi:
  1. GAS_URL sudah benar? Pastikan berakhir /exec (bukan /dev)
  2. HTML sudah di-push ke GitHub? Tunggu 1-2 menit untuk GitHub Pages update (atau hard refresh dengan Ctrl+Shift+R)
  3. Deployment GAS benar? "Who has access" harus Anyone (bukan "Anyone with Google account")
  4. Kode.gs sudah di-re-deploy? Setiap kali edit Kode.gs, harus Deploy > Manage deployments > Edit > version baru
  5. SPREADSHEET_ID benar? Cek baris 18 di Kode.gs - harus sesuai URL spreadsheet Anda
  6. Autorisasi sudah? Saat deploy pertama, klik "Authorize" dan izinkan semua permission
