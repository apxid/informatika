⬇ Download
Cara pakai:
1. Download file .xlsx di atas
2. Buka Google Drive → klik New → File upload → pilih file ini
3. Setelah upload, klik kanan file → Open with → Google Sheets (Drive akan konversi ke Google Spreadsheet)
4. Deploy GAS app (paste Code.gs + Index.html) → buka URL → login admin / admin123
5. GAS app akan otomatis pakai spreadsheet yang sudah Anda upload (tidak perlu run setupInitial)

4Cara Pakai Singkat

Urutan penggunaan file-file di atas.
Langkah 1 — Setup kode: Extract gas-rekap-nilai-informatika.zip → upload folder ke GitHub (atau paste Code.gs + Index.html ke editor GAS di script.google.com).

Langkah 2 — Setup spreadsheet: Download REKAP NILAI INFORMATIKA KELAS 9.xlsx → upload ke Google Drive → buka di Google Sheets untuk konversi.

Langkah 3 — Deploy: Di editor GAS → Deploy → New deployment → tipe Web app → Execute as: Me → Who has access: Anyone with Google Account.

Langkah 4 — Login: Buka Web app URL → login dengan admin / admin123. Ubah password default via menu Config!

Langkah 5 — Test import: Download CONTOH_IMPORT_NAMA_SISWA.xlsx & CONTOH_IMPORT_NILAI_TP.xlsx → di web app, pilih kelas KELAS9A → upload file nama → import. Lalu upload file nilai, pilih sheet LM1, target LM1-TP1, kolom nilai TP1 → Preview Match → Simpan.

Langkah 6 — Test katrol: Klik toggle Mode: Nilai Akhir di header grid → lihat cell kuning (nilai < 78 di-bump jadi 78). Klik Download Excel Nilai Akhir (Katrol) untuk dapatkan file versi bumped untuk wali murid.
